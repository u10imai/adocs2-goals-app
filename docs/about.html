もくひょうアプリ(ADOC-S連携)について

最終更新: 2026年9月20日

どんなアプリか

作業療法などのリハビリテーションで、ADOC-Sのイラストをきっかけに、セラピスト・保護者・本人が話し合いながら生活の目標を決めるためのウェブアプリです。決めた目標を、場所ごとの工夫や、動作の手順(工程)に分けて、計画書(Excel)にまとめます。

主な機能

  • イラストを使った目標の選択(本人・保護者・支援者が順番に選ぶ)
  • 目標の絞り込みと、実施する場所の設定
  • 目標を工程に分け、調整の工夫(道具・環境、支援・声かけ、活動の形式・規模)を記録
  • 振り返りの日の設定(カレンダーへの追加)
  • 計画書のExcel出力

利用できる人

アカウントを持ってログインできるのは、支援を担当するセラピストです。本人や保護者は、セラピストと一緒に画面を見ながら参加します。一般の方が自由に登録して使うサービスではありません。

データのバックアップについて

記録したデータは、運営者(管理者)が、自分自身のGoogleドライブに毎日バックアップします。この機能は、運営者本人のGoogleアカウントだけで使うためのもので、Googleが提供するドライブの機能(drive.fileの範囲)の中で、このアプリが作ったフォルダとファイルだけを扱います。詳しくはプライバシーポリシーをご覧ください。

About this app (English summary)

This is a web application for occupational therapists, parents, and children to choose daily-life goals together using ADOC-S illustrations, break the goals into steps, and export a plan as an Excel file. Only the therapists who are given an account can log in. The site operator backs up the app's data to the operator's own Google Drive every day, using only the drive.file scope. See the Privacy Policy.
