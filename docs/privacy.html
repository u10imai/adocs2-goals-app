プライバシーポリシー

最終更新: 2026年9月20日

このページは、「もくひょうアプリ(ADOC-S連携)」のバックアップ機能(Google Cloud上のアプリ名: adocs2-backup)が、Googleのユーザーデータをどのように扱うかを説明するものです。アプリの説明もご覧ください。

1. 取得するGoogleのユーザーデータ

  • このバックアップ機能が利用するGoogleの許可範囲(スコープ)は、https://www.googleapis.com/auth/drive.file の1つだけです。
  • この範囲では、このアプリ自身が作成したフォルダとファイルにだけアクセスできます。Googleドライブにあるその他のファイルを、閲覧・変更・削除することはできません。
  • メールアドレス、氏名、連絡先など、Googleアカウントのその他の情報は取得しません。

2. 利用目的

運営者(このアプリの管理者本人)のGoogleドライブに、アプリの記録データのバックアップファイルを、毎日保存するためだけに使います。

3. 第三者への提供・その他の利用

  • Googleのユーザーデータを、第三者に提供・販売・共有することはありません。
  • 広告や、ユーザーのプロファイリング、AIモデルの学習には使用しません。
  • このアプリによる、Google APIから受け取った情報の使用と、他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー(限定的な使用の要件を含む)に準拠します。

4. 利用できる人

このバックアップ機能のGoogleアカウントの認可を行うのは、運営者本人だけです。一般の利用者に、Googleアカウントでのログインや認可を求めることはありません。

5. 保管とセキュリティ

  • 認可の情報(リフレッシュトークン等)は、GitHubの暗号化された保管領域(Secrets)にのみ保存し、公開されるファイルには含めません。
  • バックアップファイルは、運営者のGoogleドライブの専用フォルダに保存され、他の人と共有しません。
  • バックアップされるのは、アプリの記録データです。データは、運営者の管理下にある、Supabaseのデータベースから取得します。

6. 保存期間と削除

バックアップファイルは、運営者が削除するまでドライブに残ります。運営者は、いつでも、Googleアカウントの「サードパーティのアクセス」からこのアプリのアクセス権を取り消し、ドライブのフォルダを削除できます。取り消した後は、このアプリはGoogleドライブにアクセスできません。

7. お問い合わせ

運営者への連絡は、GitHubのIssues(https://github.com/u10imai/adocs2-goals-app/issues)からお願いします。

※ Issuesは誰でも読める場所です。個人情報や、お子さんに関する情報は書き込まないでください。

8. 改定

この方針を変更する場合は、このページで告知し、最終更新日を改めます。

Privacy Policy (English summary)

The backup function of this app (Google Cloud app name: adocs2-backup) requests only the https://www.googleapis.com/auth/drive.file scope. It can access only the folder and files that the app itself creates in the site operator's own Google Drive; it cannot view, modify, or delete any other file. It does not access other Google account data such as email address or contacts. The data is used only to save daily backups of this app's records to the operator's Drive. Google user data is not sold, shared with third parties, used for advertising, profiling, or to train AI models. The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Only the operator authorizes this app. Authorization credentials are stored only in encrypted GitHub Secrets. The operator can revoke access at any time from the Google Account's third-party access page and delete the backup folder. Contact: please open an issue at https://github.com/u10imai/adocs2-goals-app/issues (issues are public; do not post personal information).
